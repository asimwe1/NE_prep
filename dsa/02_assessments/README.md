# Assessment Guide

This folder is split by assessment type and then by `official` source files versus answer/reference code.

## Structure

- `exams/`
  Past papers and other exam materials.

- `exercises/`
  Exercise sheets and matching answer/reference `.cpp` files.

- `group_work/`
  Group work sheets and topic-based reference `.cpp` files.

## Notes

- Files inside `official/` are the original assessment documents.
- Files inside `answers/`, `submission/`, or `reference_examples/` are plausible code answers or supporting examples.
- The `NE_DSA_Practical.docx` paper is filed under:
  `exams/past_papers/ne_dsa_practical/official/`
- Its matching practical answer is filed under:
  `exams/past_papers/ne_dsa_practical/submission/`
- The GitHub repo you provided is filed separately under:
  `exams/past_papers/dsa_2024_github_answer_repo/`
  so it stays distinct from the local graph practical.
