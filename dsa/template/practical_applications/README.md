# Practical Application Templates

This folder is for full DSA practical-style applications.

These are not just syntax examples. They are reusable patterns for exam questions where the scenario changes but the structure stays similar.

## Included scenarios

- `smart_parking_management/`
  Hash-map and slot-allocation application for parking slots, active vehicles, billing, and reports.

- `road_budget_manager/`
  Graph and matrix application for cities, roads, and budgets.

- `hospital_management/`
  Linked-list application for patients, doctors, and appointments.

## How to use them

When you get a new practical:

1. Identify the data structure being tested.
2. Pick the closest scenario template.
3. Rename entities, menu items, and validation rules.
4. Keep the same application structure:
   - register records
   - store relations
   - search/display data
   - save or print results

## Reusable practical patterns

- Parking management pattern:
  best for slot allocation, availability tracking, active records, completed transactions, and fee calculation.

- Graph/Matrix pattern:
  best for roads, transport, cities, network links, costs, adjacency, and budgets.

- Linked-list pattern:
  best for hospital, school, library, customer, booking, and service-record systems.
