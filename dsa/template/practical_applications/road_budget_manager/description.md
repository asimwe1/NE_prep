# Road Budget Manager Template

## Scenario Type

This template fits practical exams about:

- cities and roads
- transport planning
- adjacency matrices
- cost or budget management
- network links between locations

## Data Structure Focus

- `vector<string>` for entity names
- adjacency matrix for connections
- budget/cost matrix for weighted relationships

## What this pattern usually tests

- registering existing records
- adding new records
- creating relationships between records
- assigning values to those relationships
- searching and displaying data
- file saving or console reporting

## How to adapt it

Change these parts when the scenario changes:

- city names -> locations, branches, stations, departments
- road budget -> distance, cost, fee, bandwidth, travel time
- road relationship -> connection, route, network edge
