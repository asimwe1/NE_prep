# Template Guide

This folder contains reusable starting points for common DSA assessment scenarios.

## Folders

- `exam_submission/`
  Starter/example files for practical or past-paper style coding questions.

- `exercise_answer/`
  Small answer-style examples for worksheet questions.

- `group_work_submission/`
  Example code you can adapt when a work item needs a demo implementation.

- `practical_applications/`
  Full application-style templates based on common national-exam practical patterns.
  Each scenario includes:
  - a description `.md`
  - a working answer `.cpp`

## Usage

- Keep the original assessment document in `02_assessments/.../official/`
- Copy the closest starter from here when you need a fresh answer file
- Rename the copied file to match the exact question you are submitting
- For practical exams, start from `practical_applications/` when the paper is asking for a full console application around a real-world scenario
