# Utility Billing System

This folder contains the official Java practical workspace for the utility billing system.

## Local Setup

1. Copy `.env.example` to `.env`.
2. Update the database, JWT, email, and admin values for your machine.
3. Keep `.env` local only.

## Notes

- `docs/` keeps the supporting design material.
- `target/` is generated build output and should stay untracked.
- `.idea/` is local IDE state and should stay untracked.
