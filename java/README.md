# Java Workspace

This workspace is organized for Java NE exam preparation, templates, and multiple Spring-based projects.

## Current Project

- `erp_system/` - existing ERP project kept in its current location

## Add New Projects Here

- `projects/` - full standalone Java projects other than `erp_system`

## Reusable Templates

- `templates/microservices/` - Java microservice templates
- `templates/springboot-starters/` - Spring Boot starter projects
- `templates/common-libs/` - shared library or utility templates

## Exam Preparation

- `exam-prep/notes/` - theory notes and quick reference material
- `exam-prep/practice-projects/` - mock builds and timed practice work
- `exam-prep/past-papers/` - past exam tasks, prompts, or solutions

## Exam Workspace

- `exam/official/` - final exam work area
- `exam/submissions/` - packaged submissions, exports, or backups

## Shared Assets

- `shared/docker/` - reusable Docker and Compose snippets
- `shared/sql/` - SQL setup scripts, seed files, and schema notes
- `archive/` - old experiments, outdated templates, and backups

## Suggested Usage

1. Keep `erp_system` as the current main project.
2. Put every new standalone project inside `projects/`.
3. Copy starter code from `templates/` instead of mixing templates with real projects.
4. Keep exam prep material in `exam-prep/` and reserve `exam/official/` for the actual exam.
